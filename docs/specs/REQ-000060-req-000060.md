## 1. Global Conventions

The following apply to every new shell file in `lib/observability/`.

### 1.1 File header

Every new file begins:

```bash
#!/usr/bin/env bash
# <filename> -- <one-line description> (REQ-000060 / issue #635)
# Part of TDD: docs/tdd/REQ-000060-req-000060.md §<section>
#
# Dependencies: jq (1.6+), coreutils (stdbuf/gstdbuf, optional), lsof (optional)
# Sources: (list any other lib files it sources)

set -uo pipefail
# NOTE: `-e` is deliberately NOT set at file scope. Individual functions
# document their exit-code semantics. Observability MUST NOT wedge the
# supervisor on partial failure (TDD §7.2).
```

### 1.2 Portability constraints

- **Bash 3.2 compatible** (macOS system bash). No `mapfile`, no `[[ -v ]]`,
  no `${var@Q}`, no associative arrays without a `declare -A` fallback.
- **Coreutils detection.** Prefer `gstdbuf`/`gtimeout`/`gdate` when
  available; fall back to `stdbuf`/`timeout`/`date`. Every helper that
  needs a millisecond timestamp uses:

  ```bash
  now_ms() {
      if command -v gdate >/dev/null 2>&1; then
          gdate +%s%3N
      elif date +%N 2>/dev/null | grep -q '^[0-9]'; then
          date +%s%3N
      else
          # macOS BSD date: pad with 000
          echo "$(date +%s)000"
      fi
  }
  ```

- **ISO-8601 UTC timestamp with millisecond precision** (used in
  `session-stuck-<iso>.json` filenames and `captured_at` fields):

  ```bash
  iso_ms() {
      if command -v gdate >/dev/null 2>&1; then
          gdate -u +%Y-%m-%dT%H-%M-%S.%3NZ
      else
          # BSD date: no %N; use python fallback (Python 3.7+ is a plugin dep already)
          python3 -c "import datetime; print(datetime.datetime.utcnow().strftime('%Y-%m-%dT%H-%M-%S.%f')[:-3]+'Z')"
      fi
  }
  ```

  Filename form uses `-` between H, M, S to remain filesystem-safe on
  case-insensitive filesystems; JSON `captured_at` fields use canonical
  `T`/`:` separators — see §4.6 for the two variants.

### 1.3 Atomic file write helper

Every writer of a JSON file (baseline, progress, snapshot) uses one
shared helper:

```bash
# atomic_write_json(path, json_str) -> 0 on success, non-zero on failure
# Semantics: writes to <path>.tmp.<pid>.<epoch>, chmods 0600, renames.
# Never leaves a partial file at <path>.
atomic_write_json() {
    local path="$1" content="$2"
    local dir tmp
    dir="$(dirname "$path")"
    mkdir -p "$dir" 2>/dev/null || return 1
    chmod 0700 "$dir" 2>/dev/null || true
    tmp="${path}.tmp.$$.$(date +%s)"
    printf '%s\n' "$content" > "$tmp" || { rm -f "$tmp"; return 1; }
    chmod 0600 "$tmp" 2>/dev/null || true
    mv -f "$tmp" "$path" || { rm -f "$tmp"; return 1; }
    return 0
}
```

This helper is defined in `session_transcript.sh` (first-loaded file in
the observability set) and reused by every other file via
`source`-once idiom:

```bash
if ! declare -F atomic_write_json >/dev/null 2>&1; then
    _OBS_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    # shellcheck source=session_transcript.sh
    source "${_OBS_DIR}/session_transcript.sh"
fi
```

### 1.4 Feature-flag env var

`AUTONOMOUS_DEV_OBSERVABILITY` (default `"1"`). When set to `"0"`, T7's
wiring bypasses every observability call (INV-4). Individual library
files do NOT self-gate on this var — the gate is centralized in
`dispatch_phase_session`. Library functions are always callable.

### 1.5 Effect discipline

Every library function documents its exit-code semantics in a header
comment above the function definition and returns non-zero (never
`exit`) on failure. This preserves callers' `|| true` guards.

## 2. TASK-001 — `session_transcript.sh` API Contract

### 2.1 Public functions

```bash
# atomic_write_json(path, content) -> 0|non-zero
#   (see §1.3)

# run_streamed_session(timeout_bin, timeout_secs, spawn_script,
#                      state_file, phase, agent, prompt, output_file) -> int
#
# Arguments (all positional, all required — pass "" for empty):
#   $1 timeout_bin   Absolute path to `timeout`/`gtimeout`, or "" to run
#                    without a wall-clock cap.
#   $2 timeout_secs  Integer seconds. Ignored when $1 is "".
#   $3 spawn_script  Absolute path to spawn-session.sh.
#   $4 state_file    Passed through as spawn-session $1.
#   $5 phase         Passed through as spawn-session $2.
#   $6 agent         Passed through as spawn-session $3.
#   $7 prompt        Passed through as spawn-session $4.
#   $8 output_file   Absolute path to the transcript. tee -a target.
#
# Returns:
#   The exit code of the spawn-script (PIPESTATUS[0]). tee's exit code
#   is ignored. A failure of `timeout` propagates as 124 in the standard
#   GNU way.
#
# Side effects:
#   - Appends to $output_file (never truncates).
#   - Writes nothing else. Never touches stdin.
#
# Preconditions:
#   - $output_file's parent directory MUST exist.
#   - $spawn_script MUST be executable via `bash`.
#
# Portability:
#   - Detects gstdbuf, then stdbuf, then falls back to no line-buffering.
#     Fallback is not an error; the transcript is still tee'd.
```

### 2.2 Implementation shape (reference)

```bash
run_streamed_session() {
    local timeout_bin="$1" timeout_secs="$2" spawn_script="$3"
    local state_file="$4" phase="$5" agent="$6" prompt="$7"
    local output_file="$8"

    local stdbuf_bin=""
    if command -v gstdbuf >/dev/null 2>&1; then
        stdbuf_bin="$(command -v gstdbuf)"
    elif command -v stdbuf >/dev/null 2>&1; then
        stdbuf_bin="$(command -v stdbuf)"
    fi

    local -a runner=()
    if [[ -n "$timeout_bin" ]]; then
        runner=("$timeout_bin" --kill-after=10s "$timeout_secs")
    fi
    if [[ -n "$stdbuf_bin" ]]; then
        runner+=("$stdbuf_bin" -oL -eL)
    fi
    runner+=(bash "$spawn_script" "$state_file" "$phase" "$agent" "$prompt")

    "${runner[@]}" 2>&1 | tee -a "$output_file" > /dev/null
    return "${PIPESTATUS[0]}"
}
```

**Note.** `sample_count` = `length(samples_ms)` at all times. `p50_ms`,

### 3.3 Public functions

```bash
# phase_baselines_record(phase, elapsed_ms, exit_code) -> 0|non-zero
#
# Behavior:
#   1. Skip (return 0) if exit_code == 124 (ignore-124 rule).
#   2. Acquire lock at <baseline_dir>/phase-baselines.json.lock via
#      `set -o noclobber; > "$lock" 2>/dev/null || fail`.
#      On lock busy > 500 ms, log to stderr, return 1.
#   3. Read existing file; if missing/empty, treat as `{"schema_version":1,
#      "updated_at":"<iso>","phases":{}}`.
#   4. If parse fails, rename to `<file>.corrupt-<iso_ms>` and treat as empty.
#   5. Append elapsed_ms to phases[$phase].samples_ms; cap at 200 (drop oldest).
#   6. Recompute p50 (index n*0.5, floor), p95 (index n*0.95, floor), mean
#      (integer division) over samples_ms.
#   7. Set sample_count = length; last_updated = now (ISO).
#   8. Set top-level updated_at = now.
#   9. atomic_write_json.
#  10. Remove lock file.
#
# Env overrides:
#   AUTONOMOUS_DEV_BASELINE_MAX_SAMPLES  default 200
#
# Return: 0 on success or on ignore-124 skip; 1 on any hard failure.

# phase_baselines_read(phase) -> stdout JSON
#
# Behavior:
#   - If file missing / phase absent → prints `{}` to stdout, returns 0.
#   - Else prints `{"p50_ms":N,"p95_ms":N,"mean_ms":N,"sample_count":N}` (no samples array).
#   - Corrupt file → same as missing (do NOT throw); one-time stderr warning.
```

### 3.4 Percentile arithmetic (exact formula)

Given `samples = samples_ms` (unsorted, chronological order):

```
sorted = jq -c 'sort'
n      = length(sorted)
p50    = sorted[floor(n * 0.5)]   if n >= 1 else null
p95    = sorted[floor(n * 0.95)]  if n >= 1 else null
                                  (clamped: if index >= n, use n-1)
mean   = floor(sum(sorted) / n)   if n >= 1 else null
```

Reference jq implementation:

```jq
(.samples_ms | sort) as $s
| ($s | length) as $n
| . + {
    p50_ms:  (if $n == 0 then null else $s[($n * 0.5  | floor)] end),
    p95_ms:  (if $n == 0 then null
              else $s[([($n * 0.95 | floor), ($n - 1)] | min)] end),
    mean_ms: (if $n == 0 then null else ($s | add / $n | floor) end),
    sample_count: $n
  }
```

### 3.5 Concurrency contract

- One `phase-baselines.json.lock` file guards the whole file (all phases).
- Lock acquisition uses `set -o noclobber` and a trap:
  ```bash
  local lock="${base_dir}/phase-baselines.json.lock"
  local acquired=0
  ( set -o noclobber; : > "$lock" ) 2>/dev/null && acquired=1
  trap '[[ "$acquired" == "1" ]] && rm -f "$lock"' EXIT
  ```
- Stale-lock rule: if `stat` reports the lock's mtime is > 60 seconds
  old, delete it and retry once.

**Note.** The `request_id` string is passed through from the caller

### 4.2 Public functions

```bash
# heartbeat_start(req_dir, output_file, progress_file,
#                 request_id, phase, phase_start_ms) -> stdout: bg PID
#
# Forks a background subshell that loops until it receives SIGTERM.
# Each iteration:
#   1. Read $output_file: bytes = `wc -c` (0 if missing);
#      last_mtime = ISO-8601 UTC of file mtime (or null if missing/never modified).
#   2. delta_bytes = bytes - last_sample.bytes (0 on first sample; clamp to >=0).
#   3. silent_seconds = (now - last_mtime) in whole seconds (0 if bytes==0 and last_mtime==null).
#   4. Build sample JSON per §4.1 with status="running".
#   5. Read phase baselines via phase_baselines_read; build cfg JSON
#      from AUTONOMOUS_DEV_HS_* env vars (see §4.3).
#   6. Invoke detect_hung sample cfg baselines; capture verdict JSON.
#   7. Merge verdict into sample.anomaly and, if verdict.verdict=="suspected",
#      set sample.status="suspected".
#   8. atomic_write_json progress_file sample.
#   9. If verdict.verdict=="suspected":
#        stuck_snapshot_advisory ... || true
#        emit_session_hung_suspected ... || true
#      (Both guarded; failures MUST NOT wedge the loop.)
#  10. sleep $HB_INTERVAL_S (respecting SIGTERM).
#
# Returns:
#   Prints the bg PID to stdout; the caller captures it. Exit 0 always.
#
# Env (with defaults):
#   AUTONOMOUS_DEV_HB_INTERVAL_S          15
#
# Note: The sidecar's own PID is NOT the session PID. The session PID
# passed into sample.session_pid is the pipeline's leader (recorded by
# the wiring in dispatch_phase_session — v1 accepts null when
# unavailable; the sidecar is not required to discover it).

# heartbeat_stop(pid, progress_file) -> 0
#
# Behavior:
#   1. kill -TERM $pid 2>/dev/null || true
#   2. Wait for $pid up to 500 ms (poll every 50 ms with kill -0).
#      If still alive after 500 ms, kill -KILL. (This is the hard cap
#      — the sidecar loop must respect SIGTERM within 500 ms.)
#   3. Read progress_file; overwrite with the same JSON but
#      status="exited", ts=now(), elapsed_ms=now-phase_start (from the file).
#   4. Return 0.
```

### 4.3 Config env vars (heartbeat + detector)

## 5. TASK-004 — `hung_session_detector.sh` API Contract

### 5.1 Public function

```bash
# detect_hung(sample_json, baselines_json, cfg_json) -> stdout: verdict JSON
#
# Pure function of three JSON string arguments. Writes exactly ONE line
# of JSON to stdout. Reads NO files, writes NO files, spawns nothing
# other than `jq`.
#
# Argument JSON shapes:
#   sample_json    per §4.1 (may omit `anomaly`)
#   baselines_json per §3.2 phase entry: {p50_ms, p95_ms, mean_ms, sample_count}
#                  (may be {} for cold-start)
#   cfg_json       per §4.3: {silent_stall_s, anomaly_multiplier, min_baseline_samples}
#
# Output shape:
#   {"verdict": "ok" | "suspected",
#    "reason":  "silent_stall" | "elapsed_over_p95" | null,
#    "evidence": {
#      "silent_seconds":       <int>,
#      "elapsed_ms":           <int>,
#      "p95_ms":               <int|null>,
#      "elapsed_vs_p95_ratio": <number|null>,
#      "sample_count":         <int>
#    }}
#
# Precedence when both conditions fire: silent_stall wins
# (it's the stronger, more actionable signal per TDD §7.3).
#
# Return: 0 always (pure). Non-zero only if inputs are invalid JSON
# — in that case, prints {"verdict":"ok","reason":null,"evidence":{}}
# to stdout and returns 2.
```

### 5.2 Truth table (exhaustive)

Let `stall = cfg.silent_stall_s`, `mult = cfg.anomaly_multiplier`,
`min = cfg.min_baseline_samples`, `p95 = baselines.p95_ms`,
`n = baselines.sample_count`, `silent = sample.transcript.silent_seconds`,
`elapsed = sample.elapsed_ms`.

```
if silent >= stall:
    -> {verdict:"suspected", reason:"silent_stall"}
elif p95 != null and n >= min and (elapsed / p95) >= mult:
    -> {verdict:"suspected", reason:"elapsed_over_p95"}
else:
    -> {verdict:"ok", reason:null}
```

`elapsed_vs_p95_ratio` in `evidence` is `elapsed / p95` when both are
defined and `p95 > 0`, else `null`.

### 6.4 `session.*` block collection rules

- **ps.** Execute `ps -p <pid> -o pid,tty,stat,time,args`. If exit
  nonzero or output has ≤ 1 line, set `ps_line = "unavailable"` and
  `pid = null`. On success set `ps_line` to the second line
  (whitespace-collapsed) and `pid = <pid>`.
- **lsof.** Execute `lsof -p <pid> -F ftn` (portable field-format).
  On failure (nonzero exit, or `command -v lsof` empty):
  - `open_fds = []`
  - `lsof_truncated = false`
  - `lsof_error = "unavailable"`
  On success: parse rows into `{fd, type, name}`. Cap at
  `AUTONOMOUS_DEV_HS_LSOF_MAX_ROWS` (default 200); set
  `lsof_truncated = true` when the cap is hit; `lsof_error = null`.
  **Redaction (mandatory):** for any row whose `name` begins with
  `/Users/` and contains `/private/`, OR begins with
  `/Library/Keychains/`, replace `name` with `"<redacted>"`.
- **has_network_fd** derivation (used by recovery hint): true iff any
  `open_fds[*].type` is one of `IPv4`, `IPv6`, `unix`.
- **has_open_transcript_write** derivation: true iff any `open_fds[*]`
  has `.name == $output_file` AND `.fd` string ends with `w` or `u`
  (write / update modes in lsof's convention).

### 6.5 `transcript.*` block collection rules

- `path = $output_file`.
- `bytes = wc -c < $output_file` (0 if missing).
- `last_mtime = ISO-8601 UTC of file mtime`, else `null`.
- `silent_seconds = now - last_mtime` (whole seconds), 0 if `last_mtime` null.
- `tail_128_lines`: `tail -c 65536 "$output_file" | tail -n 128`,
  each line becomes one array element (raw string, JSON-escaped).
  Both bounds MUST be applied (bytes-first, then lines).
- If the file is missing, `tail_128_lines = []`.

### 6.6 `recovery_hint` rule table

Compute `has_net = has_network_fd`, `has_write = has_open_transcript_write`.

| `reason` | `has_net` | `has_write` | Hint |
|---|---|---|---|
| `silent_stall` | true  | true  | `"API stall likely; consider retry after cool-off"` |
| `silent_stall` | false | true  | `"Agent is spinning without I/O; consider raising log verbosity"` |
| `silent_stall` | true  | false | `"Session stalled with transcript closed; check for output redirect issues"` |
| `silent_stall` | false | false | `"Session stalled with no observed activity; inspect ps for zombie/defunct"` |
| `elapsed_over_p95` | *  | *  | `"Phase running >Nx historical p95; not necessarily hung — inspect transcript tail"` |
| `hard_timeout` | *  | *  | `"Wall-clock timeout reached; see phase_baselines to tune timeout"` |
| `soft_timeout_with_progress` | * | * | `"Soft timeout reached WITH progress; supervisor will re-enter"` |
| `agent_exited_nonzero` | * | * | `"Agent exited without phase-result; check transcript tail for error line"` |
| `kill_signal` | * | * | `"Session received an external kill; check parent supervisor for context"` |

For rows using `*`, the hint is the same regardless of FD state.

### 6.7 Filename rules

- Pattern: `session-stuck-<YYYY-MM-DDTHH-MM-SS.sssZ>.json` (note `-`
  between H, M, S — filesystem-safe).
- Collision resolution: if the target path already exists, retry with
  `-1`, `-2`, ... suffix inserted before `.json` (max 9 retries).

### 11.1 Blocker: `event_append` request_id regex

`plugins/autonomous-dev/lib/state/event_logger.sh` line 82 enforces
`^REQ-[0-9]{8}-[0-9a-f]{4}$`. REQ-000060 is a 6-digit id

**Recommended handling.** The three emit_* wrappers guard on
`event_append`'s return; a rejection triggers `|| true` at every call
site (per §7.2 recovery flow), so dispatch is not broken. However,
T7-E6 would then never assert positive. Options for T7 executor:

1. Accept T7-E6 as best-effort: skip the assertion when the request_id
   is 6-digit form. Preferred for landing this ticket.
2. File a separate follow-up to relax the regex to
   `^REQ-([0-9]{6,8})(-[0-9a-f]{4})?$` — out of scope here.

The spec DOES NOT prescribe fixing the regex; it flags it and
recommends option 1 for T7-E6.

## 12. Implementation Notes

### 12.1 Patterns to follow

- **Runner array pattern** (bash 3.2 safe array of args) — see
  `bin/spawn-session.sh` for prior art; used in §2.2.
- **Atomic tmp+rename** — see
  `lib/state/state_file_manager.sh` and `lib/state/trigger_store.ts`
  for prior art. Mirrored in §1.3.
- **`ensure_file_permissions` helper** — already exported by
  `state_file_manager.sh`. If more permission plumbing is needed by
  the new files, reuse it rather than re-implementing.
- **`event_append` failure discipline** — every emit call site uses
  `|| true`. Never `set -e` around observability calls.

### 12.2 Gotchas

- **`stdbuf` vs `gstdbuf`.** macOS ships neither; Homebrew's coreutils
  installs `gstdbuf`. The fallback path (no line-buffering, tee-only)
  must be exercised by tests (T1-U3) so we do not accidentally regress
  the fallback.
- **`PIPESTATUS[0]` in bash 3.2 subshells.** Works correctly, but
  `set -e` will short-circuit before `PIPESTATUS` is read. Use
  `set -uo pipefail` (no `-e`) in the observability subshell (§8.1.2).
- **Sidecar shutdown.** `heartbeat_stop` MUST send SIGTERM and poll for
  up to 500 ms; do NOT `wait` unconditionally — a wedged sidecar would
  block the parent forever. After 500 ms, escalate to SIGKILL.
- **File-conflict guarantee.** Each track works on disjoint files
  (per plan §Parallel Execution Schedule). The only shared mutations
  are (a) `event_logger.sh` line 17–25 (T6), (b) `supervisor-loop.sh`
  (T7), (c) `spawn-session.sh` (T7), (d) `config/defaults.json` (T7),
  (e) `autonomous-dev.sh` (T8). None of these files is touched by more
  than one task.

  append + validation pattern the emitters delegate to.
